# Indian Retail Fuel Price BI Dashboard

## Overview
A Business Intelligence dashboard for analysing Indian petrol and diesel prices, price changes, volatility, and major price shocks.

## Data
- Source: PPAC (Government of India)
- Cities: Delhi, Mumbai, Chennai, Kolkata
- Fuel: Petrol & Diesel
- Period: 2017–2026
- Records: 27,112
- No Kaggle / No pre-transformed data

## Technologies
- Python & Pandas
- MySQL & SQL
- Power BI
